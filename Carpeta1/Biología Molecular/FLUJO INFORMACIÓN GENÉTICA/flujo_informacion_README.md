# Título:  Flujo de la Información Genética 

**Descripción:** Ilustración vectorial representando el proceso de flujo de la información en células eucariontes. El diagrama muestra una célula eucariota, el proceso de transcripción incluyendo la maduración del mRNA, el proceso de traducción y un cuadro con el código genético.

**Contenido**: La carpeta contiene un archivo de vectores SVG en el que se creo la imagen utilizando *Inkscape* y un archivo PNG del diagrama.

**Autor:** Ilustración realizada por Ana Laura Pérez Juárez con apoyo de la Unidad de Bioinformática del IFC, UNAM.

**Año:** 2026
