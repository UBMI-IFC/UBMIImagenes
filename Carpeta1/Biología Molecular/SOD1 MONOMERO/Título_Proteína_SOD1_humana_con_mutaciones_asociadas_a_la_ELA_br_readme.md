# **Título:** Proteína SOD1 humana con mutaciones asociadas a la ELA   <br>   

**Descripción:** Esta ilustración representa la proteína SOD1 humana con mutaciones asociadas a la esclerosis lateral amiotrófica (ELA), en dónde pierde la conformación de heterodímero, para permanecer en una forma nomomeríca alterada. Las mutaciones asociadas con ELA, no permiten la formación de la hoja beta plegada, la proteína expone el sitio catalítico y empieza a formar agregados porteícos. Este es un recurso visual para contextualizar el estudio de variantes de SOD1 relacionadas con esta enfermedad neurodegenerativa.<br>
