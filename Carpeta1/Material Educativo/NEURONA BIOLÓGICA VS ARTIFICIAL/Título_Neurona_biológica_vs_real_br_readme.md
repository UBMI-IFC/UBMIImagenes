# **Título:** Neurona biológica vs real   <br>   

**Descripción:** Ilustración comparativa entre una neurona biológica y una neurona artificial, destacando las similitudes entre sus componentes y procesos de procesamiento de información. La imagen permite visualizar cómo el funcionamiento de las neuronas biológicas puede servir como inspiración para el diseño de modelos computacionales de redes neuronales. <br>
