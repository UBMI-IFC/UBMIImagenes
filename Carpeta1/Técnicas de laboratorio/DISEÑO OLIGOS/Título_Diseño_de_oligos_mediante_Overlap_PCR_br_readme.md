# **Título:**  Diseño de oligos mediante Overlap PCR  <br>   

**Descripción:** 
Esta ilustración esquematiza el diseño de oligonucleótidos para la técnica de Overlap PCR, una técnica en la que se utilizan dos pares de oligos para generar tres productos de PCR, el primero utiliza el oligo forward que flanquea al gen + el reverse que contiene la mutación, el segundo el forward que contiene la mutación + el reverse que flanquea el gen. Estos dos productos se mezclan para generar el DNA guía de la tercer reacción de PCR, que utiliza los oligos forward y reverse que flanquean al gen, obteniendo la secuencia funcional del gen que contiene la mutación puntual que se desea incorporar a una célula. Este es un recurso visual para explicar estrategias de ingeniería genética y mutagénesis dirigida.<br>
