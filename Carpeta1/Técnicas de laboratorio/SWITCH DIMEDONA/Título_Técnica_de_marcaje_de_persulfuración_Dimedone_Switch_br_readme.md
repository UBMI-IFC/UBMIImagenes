# **Título:**  Técnica de marcaje de persulfuración: Dimedone Switch  <br>   

**Descripción:** 
Esta ilustración representa de manera esquemática la técnica Dimedone Switch, utilizada para detectar modificaciones oxidativas de residuos de cisteína, en particular la persulfuración de proteínas. El procedimiento implica transformar químicamente los grupos persulfurados para facilitar su marcaje y posterior detección experimental.<br>
