# **Título:**  Gel 2D de proteínas <br>   

**Descripción:** Esta ilustración KRT simula un gel bidimensional (2D) de proteínas, utilizado en proteómica para separar proteínas de acuerdo con su punto isoeléctrico y peso molecular. La distribución de puntos representa diferentes proteínas separadas mediante las dos dimensiones del análisis electroforético.  <br>
