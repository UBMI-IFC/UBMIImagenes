# **Título:** Sistema CRISPR-Cas9 para reemplazo génico de hSOD1  <br>   

**Descripción:** Ilustración esquemática de un sistema de edición genética basado en CRISPR-Cas9, diseñado para reemplazar un cassette de resistencia a higromicina por el gen humano SOD1. La representación destaca de manera visual el proceso de edición dirigida y su aplicación en modelos experimentales para el estudio de mecanismos moleculares asociados con enfermedades neurodegenerativas.<br>
