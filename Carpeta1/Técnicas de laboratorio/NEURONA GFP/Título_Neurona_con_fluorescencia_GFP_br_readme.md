# **Título:**  Neurona con fluorescencia GFP <br>   

**Descripción:** Esta ilustración KRT simula la fluorescencia de una neurona que expresa GFP (Green Fluorescent Protein). La imagen representa de manera visual la señal fluorescente distribuida a lo largo del cuerpo celular y las prolongaciones neuronales, como referencia a técnicas de marcaje y visualización de células mediante proteínas fluorescentes.  <br>
