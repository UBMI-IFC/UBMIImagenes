# **Título:** Corte de Charcot   <br>   

**Descripción:** Ilustración esquemática de un corte de Charcot, utilizada para representar estructuras y regiones relevantes del sistema nervioso desde una perspectiva neuroanatómica. La imagen facilita la identificación y comprensión visual de la organización anatómica de las estructuras nerviosas. <br>
